# 📄 SQLite3 – Résumé pratique (usage courant)

## 🔹 Qu’est-ce que SQLite ?

SQLite est une base de données **légère et intégrée** :

➡️ Pas de serveur  
➡️ Un simple fichier (`.db`)  
➡️ Idéal pour applications locales (comme ton projet)

---

## 🔹 Connexion à une base

```python
import sqlite3

connexion = sqlite3.connect("eleves.db")
curseur = connexion.cursor()
```

➡️ Crée la base si elle n’existe pas

---

## 🔹 Création d’une table

```python
curseur.execute("""
CREATE TABLE IF NOT EXISTS eleves (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    prenom TEXT,
    nom TEXT
)
""")

connexion.commit()
```

➡️ `commit()` = validation des modifications

---

## 🔹 Types utilisés (cas courants)

| SQLite  | Python |
| ------- | ------ |
| TEXT    | str    |
| INTEGER | int    |
| REAL    | float  |
| NULL    | None   |

---

## 🔹 Insertion de données

```python
curseur.execute("""
INSERT INTO eleves (prenom, nom)
VALUES (?, ?)
""", ("Jean", "Dupont"))

connexion.commit()
```

➡️ Toujours utiliser `?` (sécurité + propreté)

---

## 🔹 Lecture des données

```python
curseur.execute("SELECT * FROM eleves")

lignes = curseur.fetchall()

for ligne in lignes:
    print(ligne)
```

Résultat :

```
(1, 'Jean', 'Dupont')
```

---

## 🔹 Lecture plus précise

```python
curseur.execute("SELECT prenom FROM eleves")

for ligne in curseur.fetchall():
    print(ligne[0])
```

---

## 🔹 Filtrer (WHERE)

```python
curseur.execute("""
SELECT * FROM eleves
WHERE nom = ?
""", ("Dupont",))
```

---

## 🔹 Mise à jour

```python
curseur.execute("""
UPDATE eleves
SET prenom = ?
WHERE id = ?
""", ("Paul", 1))

connexion.commit()
```

---

## 🔹 Suppression

```python
curseur.execute("""
DELETE FROM eleves
WHERE id = ?
""", (1,))

connexion.commit()
```

---

## 🔹 Suppression complète d’une table

```python
curseur.execute("DROP TABLE IF EXISTS eleves")
connexion.commit()
```

---

## 🔹 Fermeture de la base

```python
connexion.close()
```

---

## 🔹 Lecture d’un CSV → SQLite (cas réel)

```python
import csv

with open("eleves.csv", newline='', encoding="utf-8") as f:
    lecteur = csv.reader(f)
    next(lecteur)  # ignorer l'en-tête

    for ligne in lecteur:
        prenom, nom = ligne

        curseur.execute("""
        INSERT INTO eleves (prenom, nom)
        VALUES (?, ?)
        """, (prenom, nom))

connexion.commit()
```

---

## 🔹 Bonnes pratiques

- Toujours faire `commit()` après modification  
- Toujours utiliser `?` (évite les bugs et injections)  
- Fermer la connexion  
- Séparer :
  - création de la BDD
  - import CSV
  - utilisation dans l’application
